# Discs for Sale — ร้านแผ่นเกม PS5

โปรเจกต์ตัวอย่างที่รันได้ในเครื่อง: React 19 + Vite + TypeScript + React Router v7 + Zustand persist + TanStack Query v5 + Tailwind CSS 4 + DaisyUI 5 + JSON Server

## เริ่มใช้งานครั้งแรก (Windows / VS Code)

1. แตก ZIP ก่อน อย่าเปิดโปรเจกต์จากภายในไฟล์ ZIP
2. ติดตั้ง Node.js รุ่น LTS ที่มีเวอร์ชันอย่างน้อย 22.12.0: https://nodejs.org/
3. เปิด VS Code > File > Open Folder แล้วเลือกโฟลเดอร์ `ps5-disc-store` ที่มี `package.json`
4. เปิด Terminal > New Terminal แล้วตรวจ:

```bash
node -v
npm -v
```

5. ติดตั้งแพ็กเกจตามเวอร์ชันใน package-lock.json (ต้องใช้อินเทอร์เน็ตครั้งแรก):

```bash
npm ci
```

6. เปิดเว็บและ API พร้อมกัน:

```bash
npm run dev
```

7. เปิด **http://127.0.0.1:5173/** ในเบราว์เซอร์
8. ปล่อย Terminal นี้เปิดไว้ระหว่างใช้งาน กด Ctrl+C เมื่อต้องการหยุด

ครั้งถัดไปใช้เพียง `npm run dev` ไม่ต้องติดตั้งใหม่ หากไม่ได้เปลี่ยน package.json หรือ package-lock.json

ถ้า PowerShell แจ้งว่า npm.ps1 ใช้งานไม่ได้ ให้ใช้ `npm.cmd ci` และ `npm.cmd run dev` หรือเปลี่ยน Terminal เป็น Command Prompt ไม่จำเป็นต้องแก้นโยบายระบบ

ทางเลือก: ดับเบิลคลิก `START-WINDOWS.bat` เพื่อให้ติดตั้งและเปิดระบบในหน้าต่าง Command Prompt

## มีอะไรให้ลอง

- หน้าร้าน `/`: แสดง 20 เกม ค้นหาจากชื่อ/คำอธิบาย/ประเภท กรองประเภท และเรียงเกมแนะนำ ราคา หรือชื่อ
- Detail `/games/:id`: รายละเอียดแยกตาม ID เช่น `/games/1` และ `/games/2`
- Wishlist `/wishlist`: บันทึก/นำออกด้วยหัวใจ รีเฟรชหรือปิดเปิดใหม่แล้วยังอยู่ในเบราว์เซอร์เดิม
- Compare `/compare`: เลือกได้สูงสุด 2 เกม ไม่กระโดดเปลี่ยนหน้าเอง มีแถบด้านล่างแสดงจำนวนที่เลือก กดปุ่มเปรียบเทียบเมื่อพร้อม
- หากเลือกเกมที่ 3 จะมีข้อความแจ้ง และไม่แทนเกมเดิม เลิกเลือกเกมเดิมก่อน หรือเปลี่ยนเกมจาก dropdown ในหน้า Compare
- About `/about`: สมาชิก 2 คน หน้าที่ และลิงก์แหล่งข้อมูลกับเอกสาร API
- มี Skeleton ระหว่างโหลด, Error และปุ่ม Retry, สถานะรายการว่าง, รูปสำรองเมื่อโหลดรูปไม่ได้ และหน้าไม่พบข้อมูล
- กลับจาก Detail ด้วยปุ่ม "กลับไปหน้าก่อนหน้า" จะใช้ประวัติเดิมเพื่อคืนตำแหน่งเลื่อน ตัวค้นหา/กรองยังคงอยู่ระหว่างการเปลี่ยนหน้า
- คำว่า "เกมแนะนำ" อ้างจากค่า `featured` ใน db.json ไม่ใช่การจัดอันดับจากภายนอก

## สิ่งที่ต้องแก้เป็นข้อมูลจริงก่อนส่งอาจารย์

1. เปิด `src/data/team.ts` กรอกชื่อ–นามสกุล ชื่อเล่น รหัสนักศึกษา และหน้าที่จริงของทั้งสองคน
2. ใส่รูปสมาชิกจริงใน `public/images/` และแก้ `photo` ใน team.ts ให้ตรงกับชื่อไฟล์ ตอนนี้เป็น avatar ตัวอย่าง ไม่ใช่รูปถ่ายจริง
3. ตรวจคำอธิบาย จำนวนผู้เล่น รุ่นแผ่น และวันที่ของเกมให้ตรงกับข้อมูลที่กลุ่มจะนำเสนอ ราคาในชุดนี้เป็นราคาจำลอง
4. ภาพเกมที่ให้มาเป็นภาพประกอบจากหน้า PlayStation ไม่ใช่ภาพกล่องสินค้าแผ่น PS5 ที่ตรวจสอบแพ็กเกจแล้ว หากต้องการหน้าร้านสมจริงให้เปลี่ยนเป็นภาพกล่องตรงรุ่นและเพิ่มแหล่งที่มา
5. ถ่ายภาพระบบจริงครบ 5 หน้าในโฟลเดอร์ `screenshots/` หลังปรับข้อมูลเสร็จ
6. ZIP ส่งอาจารย์ใช้ชื่อ `mini_proj2_รหัสนักศึกษา.zip` ไม่มี node_modules และ dist ตามโจทย์
7. แนบ Repository ถ้ามี; การ deploy เป็นตัวเลือกแนะนำ ไม่ได้ตั้งให้ในตัวอย่างนี้

## ข้อมูลและ API มาจากไหน

ข้อมูลเกม 20 รายการอยู่ใน `db.json` โดยมี `games` เป็นอาร์เรย์ของรายการสินค้า แต่ละรายการประกอบด้วย:

| ฟิลด์ | ความหมาย |
|---|---|
| id | รหัสไม่ซ้ำ ใช้เป็น string เช่น "1" |
| title | ชื่อเกม |
| price | ราคาจำลอง เป็นตัวเลข ไม่ใส่เครื่องหมายบาท |
| cover | ตำแหน่งรูป เช่น /images/game-01.jpg |
| genre | ประเภทเกม ใช้ค้นหา กรอง และเปรียบเทียบ |
| players | ข้อมูลจำนวนผู้เล่นและโหมดการเล่น |
| platform | PS5 |
| format | แผ่นเกม |
| releaseDate | วันวางจำหน่ายเวอร์ชัน PS5 แบบ YYYY-MM-DD |
| publisher | ผู้จัดจำหน่าย |
| featured | true = แนะนำ ให้ขึ้นก่อนเมื่อเรียงเกมแนะนำ |
| description | เรื่องย่อที่เรียบเรียงสำหรับการสาธิต |

ตามที่ตกลงกัน ไม่มี `sourceUrl` ในรายการเกม รายการแหล่งข้อมูลแยกไว้ที่ `src/data/sources.ts` และ `ASSET-SOURCES.json` แล้วแสดงลิงก์ใน About

JSON Server อ่าน `db.json` แล้วเปิด API ที่ **http://127.0.0.1:3001**

- `GET /games` รายการทั้งหมด
- `GET /games/1` รายละเอียดเกม ID 1
- ID ไม่พบตอบ HTTP 404
- เปิดแบบ read-only เพราะฟังก์ชันของโปรเจกต์ใช้การอ่านข้อมูล ไม่ต้องเขียนคอลเลกชันกลับเข้า API

ฝั่ง React ใช้ `/api/games` และ Vite proxy ส่งต่อไป JSON Server ถ้า API อยู่เครื่องอื่นให้ตั้ง VITE_API_URL ตาม `.env.example` แล้วเริ่ม dev ใหม่

ขณะรัน เปิดเอกสาร API ได้ที่ **http://127.0.0.1:5173/api-docs.html**

## แยก Client State / Server State อย่างไร

- `src/api/games.ts`: fetch + ตรวจรูปแบบข้อมูล + TanStack Query options
- TanStack Query: เก็บข้อมูลเกม แคช staleTime 5 นาที และ gcTime 30 นาที ค่า staleTime ไม่ใช่การดึงข้อมูลซ้ำทุก 5 นาที แต่เป็นช่วงที่ข้อมูลยังถือว่าสด
- `src/stores/shop.ts`: Zustand เก็บ wishlistIds, compareIds, คำค้น, ตัวกรอง, วิธีเรียง และข้อความแจ้งเตือน
- persist เก็บแค่ wishlistIds และ compareIds ลง LocalStorage ไม่มีรายละเอียดเกม ชื่อ รูป ราคา หรือ response ทั้งชุด
- หน้าร้าน/Wishlist/Compare ใช้ Query key เดียวกันสำหรับรายการเกม จึงใช้แคชร่วมกัน ส่วน Detail ใช้ Query key แยกตาม ID
- `<Outlet>` แสดงหน้าภายใน Layout; `<NavLink>` ทำเมนู; `useParams` อ่าน ID; `<ScrollRestoration>` จัดการตำแหน่งเลื่อนเมื่อย้อนกลับ
- ไม่มีระบบล็อกอิน ตะกร้าชำระเงิน หรือการสั่งซื้อ เพราะขอบเขตที่ตกลงเป็นแค็ตตาล็อกแผ่นเกม + Wishlist + Compare

## คำสั่งตรวจงาน

```bash
npm run check:data
npm test
npm run build
```

ตรวจ JSON Server จริงเพิ่มเติมได้ด้วย `node scripts/check-api.mjs` (พอร์ต 3008 ต้องว่าง)

หลัง build ถ้าจะทดสอบ production build ต้องเปิด API ด้วย:

Terminal แรก:
```bash
npm run api
```
Terminal ที่สอง:
```bash
npm run preview
```
เปิด http://127.0.0.1:4173/ — ห้ามดับเบิลคลิก dist/index.html เพราะเป็น SPA และต้องมี API ทำงาน

## แก้ปัญหาเบื้องต้น

- ขึ้น "เชื่อมต่อข้อมูลเกมไม่ได้": ตรวจ Terminal ฝั่ง API และ http://127.0.0.1:3001/games แล้วกด Retry
- พอร์ตถูกใช้: ปิด Terminal โปรเจกต์เก่า หรือกด Ctrl+C ที่งานเดิมก่อนเริ่มใหม่
- รูปไม่ขึ้น: ตรวจชื่อไฟล์และ `cover` ให้ตรงกัน ตัวพิมพ์ใหญ่/เล็กมีผลเมื่อ deploy
- แก้ db.json แล้วไม่เห็นข้อมูลใหม่: JSON Server จะอ่านใหม่อัตโนมัติ ส่วนแคชในเว็บให้รีเฟรชเต็มหน้า
- อย่าแก้ node_modules และอย่าลบ package-lock.json เพื่อแก้ error ให้ดูข้อความจริงก่อน
- localStorage แยกตาม origin: localhost และ 127.0.0.1 เป็นคนละ origin ใช้ URL เดิมเพื่อดู Wishlist เดิม
