Discs for Sale — Mock REST API

API ของโครงงาน เปิดด้วย JSON Server 0.17.4 จากไฟล์ db.json จำนวน 20 เกม ราคาเป็นข้อมูลจำลอง

Base URL ในเครื่อง: http://127.0.0.1:3001
ฝั่งเว็บผ่าน Vite proxy: /api

Endpoints

MethodPathผลลัพธ์
GET/gamesGame[] รายการเกมทั้งหมด, HTTP 200
GET/games/1Game รายละเอียดตาม ID, HTTP 200
GET/games/:idหากไม่พบ ID ตอบ HTTP 404

API เปิดแบบ read-only ไม่มี authentication สำหรับการสาธิตในเครื่อง Wishlist และ Compare เป็นข้อมูลฝั่งผู้ใช้ เก็บเฉพาะ ID ใน Zustand + LocalStorage

ตัวอย่าง Game

{
  "id": "1",
  "title": "Marvel’s Spider-Man 2",
  "price": 1990,
  "cover": "/images/game-01.jpg",
  "genre": "Action / Adventure",
  "players": "1 คน",
  "platform": "PS5",
  "format": "แผ่นเกม",
  "releaseDate": "2023-10-20",
  "publisher": "Sony Interactive Entertainment",
  "featured": true,
  "description": "เรื่องย่อเกม..."
}

price เป็น number, featured เป็น boolean และฟิลด์อื่นเป็น string เส้นทางรูปอ้างอิงจากเว็บ Vite ใน public/images ไม่ใช่จาก JSON Server

การใช้งาน

fetch('/api/games')
fetch('/api/games/1')

ในแอปจริงเรียกผ่าน TanStack Query โดย staleTime 5 นาที เพื่อใช้แคชข้อมูลเดิมร่วมกัน ไม่เก็บข้อมูลเกมทั้งหมดซ้ำใน Zustand

อ่านเอกสารเครื่องมือ: JSON Server 0.17.4
