# ภาพหน้าจอที่ต้องเพิ่มก่อนส่งงาน

โฟลเดอร์นี้ยังไม่มีภาพหน้าจอระบบจริง เพราะเป็นชุดตัวอย่างสำหรับนำไปเปิดในเครื่องและปรับข้อมูลสมาชิกก่อน

หลังเปิดด้วย `npm run dev` และกรอกสมาชิกแล้ว ให้ถ่ายภาพครบ:

1. หน้าร้าน — เห็นการ์ดเกมและช่องค้นหา/กรอง/เรียง
2. Detail — เห็นชื่อเกมและรายละเอียด
3. Wishlist — กดบันทึกเกมอย่างน้อย 1 เกมก่อนถ่าย
4. About — ใช้ข้อมูลสมาชิกและรูปจริง
5. Compare — เลือกครบ 2 เกมแล้วถ่าย

แนะนำเพิ่มภาพจอมือถือและสถานะ Error/Retry เพื่อประกอบการตรวจ

ภาพ Mockup จาก Figma ไม่ใช่ภาพระบบจริงที่อาจารย์กำหนด
